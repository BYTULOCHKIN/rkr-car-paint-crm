# Логотипи марок автомобілів

`VehicleBrandAvatar` використовує спільний shadcn Avatar, локальні SVG з `public/vehicle-brands/` та реєстр `vehicleBrandLogos` у `src/components/icons.tsx`. Загальна іконка авто `Icons.car` відображається для невідомої марки або при помилці завантаження зображення. Аватар декоративний: назва марки залишається поруч текстом.

Логотипи нейтрально-сірі (`#737373`); у темній темі застосовується інверсія до світлішого сірого. Немає зовнішніх запитів за логотипами, нової залежності, змін даних автомобілів або PDF.

Нормалізація назв враховує регістр, пробіли, розділювачі та діакритичні знаки. `VW` відповідає Volkswagen; `Mercedes`, `Mercedes-Benz` та `Mercedes Benz` використовують той самий логотип. Нові марки можна підключити, додавши SVG і запис у центральний реєстр. Не будуйте шлях до файлу з довільної введеної назви марки.
