# Керування командою через Clerk

Тип: AFK. User stories: 2–4.
PRD: [Команда, ролі та виконавець замовлення](../team-roles-and-order-assignee.prd.md).

## What to build

Адміністратор відкриває команду поточної автомалярки, переглядає учасників,
запрошує співробітника, змінює роль або видаляє учасника через стандартний
інтерфейс Clerk Organizations. У CRM дві зрозумілі ролі: «Адміністратор» і
«Виконавець». Наявний серверний контекст надає список активних учасників
поточної організації для подальшого вибору виконавця.

Це завершений шлях: адміністратор запрошує учасника → той приймає запрошення →
його роль і членство стають доступними CRM; видалення закриває доступ.
Власної системи листів, запрошень чи спеціальних ролей не створюємо.

## Acceptance criteria

- [x] У навігації є зрозумілий доступ до команди поточної автомалярки; сторінка використовує стандартний заголовок проєкту.
- [x] Інтерфейс пояснює відповідність `org:admin` ролі адміністратора, а `org:member` — ролі виконавця, включно з правами на ціни та статуси.
- [x] Адміністратор може керувати запрошеннями, ролями та членством через вбудовані компоненти Clerk; нові ролі й власний механізм запрошень відсутні.
- [x] Виконавець не має адміністративних інструментів керування командою; обмеження не залежать лише від прихованої навігації.
- [x] Список активних учасників містить ідентифікатор, читабельне ім’я та роль; не передається повний Clerk User із приватними метаданими.
- [x] Очікуване запрошення не вважається активним членством. Після приєднання учасник з’являється в актуальному списку.
- [x] Після видалення учасник втрачає серверний доступ; після зміни ролі старі права не зберігаються через довіру до клієнтського кешу.
- [x] Поточна організація чітко видима; UI не керує командою іншої автомалярки після перемикання.
- [x] Тести зі змодельованими відповідями Clerk перевіряють список, ролі, запрошення в очікуванні, відсутність доступу та оновлення членства.
- [x] Інтерфейс перевірено для адміністратора й виконавця на широкому та мобільному екранах. Під час тестів не надсилаються справжні запрошення.
