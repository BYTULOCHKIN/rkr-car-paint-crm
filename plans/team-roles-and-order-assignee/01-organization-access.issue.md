# Автомалярка й ізоляція даних

Тип: AFK. User stories: 1, 5–9, 28, 30.
PRD: [Команда, ролі та виконавець замовлення](../team-roles-and-order-assignee.prd.md).

## What to build

Учасник входить через Clerk і працює в контексті вибраної автомалярки.
Організація визначає доступ до всіх даних CRM, включно з історією та друком.
Якщо організацію не вибрано, інтерфейс пояснює наступний крок і веде до вибору
або створення автомалярки. Поточний власник зберігає наявні дані й може
прив’язати їх до своєї організації; інша організація їх не отримує.

Це завершений шлях адміністратора: вибір автомалярки → перегляд і редагування
її даних → перемикання на іншу автомалярку без змішування записів і кешу.
Перевірки членства та ролі централізовані на сервері й придатні для наступних задач.

## Acceptance criteria

- [x] Поточна організація та користувач визначаються із серверної сесії Clerk; значення з форми чи URL не можуть підмінити контекст.
- [x] Підтримуються лише `org:admin` та `org:member`; невідома роль не отримує адміністративних прав.
- [x] Доступ без входу, активної організації або чинного членства закритий; користувач отримує зрозумілий шлях продовження.
- [x] Усі адміністративні операції перевіряють роль на сервері; виклик напряму від виконавця відхиляється.
- [x] Читання, зміни, історія та друк обмежені поточною автомаляркою. Ідентифікатор чужого запису не відкриває доступ до нього.
- [x] Перевірка членства не покладається лише на застарілу роль у клієнтському інтерфейсі.
- [x] Поточні клієнти, авто, заявки, замовлення, схеми кузова та історія збережені. Прив’язати стару базу може лише її чинний власник до організації, де він адміністратор.
- [x] Прив’язка старої бази однозначна й атомарна; її неможливо повторно привласнити іншій організації. Інші автомалярки починають із відокремлених даних.
- [x] Міграція повторювана й не створює вигаданих виконавців або історичних подій.
- [x] Ключі кешу містять організацію та користувача; після перемикання не показуються дані попередньої автомалярки.
- [x] Тести перевіряють два незалежні набори даних, підроблені ідентифікатори, рольові обмеження, втрату членства, міграцію й перемикання організацій у UI.
- [x] Розпочаті раніше зміни узгоджено з цим PRD; попередні вдосконалення історії збережені, перевірка типів і відповідні тести проходять.
